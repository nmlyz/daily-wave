daily-wave writes one line to a text file: a stranger, a mistaken wave, and the daily ritual that keeps the lie going. The line was picked from 36 candidates by pairwise judging against the brief — a small, recognisable mistake that turns into a habit instead of an apology. The program builds the line from two beats — the mistaken wave, the daily wave that protects the lie — and checks the result against the entry gate (length, single line, no leading or trailing space, exact judged length) before writing it, then reads the file back to confirm the bytes match.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run. The line is 111 characters, a single line, and ends on its turn.
